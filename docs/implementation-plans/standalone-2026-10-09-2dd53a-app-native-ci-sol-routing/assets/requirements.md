# Requirements

Test IDs below name focused regressions in existing runners. Live app/local/container/Sandbox acceptance requires 6.1-6.3; 7.1 proves preservation of VS Code's existing route, not a new native workflow. Static tests do not replace these live gates.

REQ-3 through REQ-13 define the new app-coordinated path. They do not replace VS Code's existing orchestration or completion semantics; REQ-18 requires their preservation.
