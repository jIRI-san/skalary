# Requirements

| ID | Requirement | Acceptance Criteria | Phases/Steps |
|----|-------------|---------------------|--------------|
| REQ-1 | Long context is retired from every active repository surface. | `.autopilot.json`, shipped examples, schemas, host/container/sandbox launchers, active skills/agents, and non-archived tests/docs neither expose nor request `long_context`; autopilot omits the context setting and CLI flag entirely; archived history is excluded. `test:AiCreditBudget.LongContextRetired` | 1.2, 1.3, 4.1, 4.2 |
| REQ-2 | One explicit cheap-first model ladder assigns the least expensive suitable model to each task class. | Routine work uses Luna/medium, standard planning/validation/review uses Terra/high, deep cross-subsystem or unresolved diagnosis uses Sol/high, and one concrete high-risk independent pass uses Opus/high; every tier uses default context and one named replacement fallback; Sol and Opus are absent from routine fallback paths. `test:AiCreditBudget.ModelRouting` | 1.1, 1.2, 1.3, 2.1, 2.3, 3.1, 3.2, 4.1, 4.2, 4.3 |
| REQ-3 | Direct work and deterministic evidence replace routine delegated validation. | Direct work defaults to zero delegated calls; one combined call is normal only for a concrete unresolved concern; every retry/replacement counts toward a three-call hard ceiling; no skill names Judge as an automatic second call; a fourth call requires a new operator decision. `test:AiCreditBudget.DelegationLimits` | 2.1, 2.2, 2.3, 4.2, 4.3 |
| REQ-4 | Autopilot defaults are inexpensive while complex work remains explicitly selectable. | Canonical and dogfood autopilot agents/config examples default to Luna, medium reasoning, and host-default context; Terra and Sol remain valid explicit model overrides; context is no longer configurable; model and effort validation fail loudly on unsupported values. `test:AiCreditBudget.AutopilotDefaults` | 1.2, 1.3, 2.1, 2.3, 4.2 |
| REQ-5 | CR/DR spend one standard call unless a concrete high-risk path warrants independent review. | A selected ordinary review uses one Terra call; Opus adds at most one independent pass only for a named security, concurrency, destructive, correctness, or architecture risk; no fixed concern matrix, model panel, automatic Judge, or unchanged-scope rerun exists; incomplete/exhausted work remains non-clean. `test:AiCreditBudget.ReviewRouting` `review:cr` | 2.1, 2.3, 4.2, 4.3 |
| REQ-6 | Premium evals minimize model cost without weakening observable behavior coverage. | Every current waza task has an explicit deterministic/subjective/delete disposition; skill execution uses Luna; Terra judges only subjective cases; deterministic graders retain refusal, injection, tool-use, and required-output checks where observable; Tier-2 remains explicit and plugin-focused and no ordinary route runs a full sweep. `test:AiCreditBudget.WazaRouting` `test:gate-isolation` | 3.1, 3.2, 3.3, 4.2 |
| REQ-7 | Frequently invoked skills use progressive disclosure and smaller recurring context. | `autopilot`, `cep`, `cip`, `ci`, `cr`, `dr`, and `si` entrypoints are each at most 4 KiB; rare detail moves to installed assets referenced from the owning branch; delegated prompts attach at most three artifacts, target 400 words, and refuse to proceed above 800 without narrowing. `test:AiCreditBudget.SkillContext` | 2.2, 2.3, 4.1, 4.2 |
| REQ-8 | Human guidance makes the 200K ceiling actionable without claiming exact enforcement. | Active guidance records 180K planned use plus a 20K reserve, links official pricing and usage dashboards, dates the price snapshot, explains weekly model-level review and explicit premium runs, and states that static instructions cannot guarantee spend. `test:AiCreditBudget.OperatorGuidance` | 1.1, 3.3, 4.1, 4.2, 4.3 |
| REQ-9 | Canonical sources, installed assets, and generated copies remain consistent without a policy service. | Existing sync/build commands propagate model, call, context, skill-asset, allowlist, registry, marketplace, and dogfood changes; focused consumer-install tests prove the shipped behavior; no credit ledger, telemetry pipeline, price registry, scheduler, model router service, or generated instruction graph is added. `test:AiCreditBudget.ConsumerInstall` | 1.2, 1.3, 2.2, 2.3, 3.2, 4.1, 4.2, 4.3 |
| REQ-10 | Existing safety and evidence boundaries survive the cost reduction. | Prompt-injection framing, secret refusal/redaction, read-only review, destructive-action approval, physical/canonical write confinement, external-format validation, criteria protection, distinct failure outcomes, focused deterministic gates, and explicit premium invocation remain; cost reduction does not weaken them. `test:AiCreditBudget.RetainedGuards` `review:cr` | 1.1, 2.1, 2.2, 2.3, 3.1, 3.2, 3.3, 4.2, 4.3 |
