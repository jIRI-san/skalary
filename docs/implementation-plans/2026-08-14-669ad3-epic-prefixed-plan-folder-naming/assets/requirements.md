# Requirements

| ID | Requirement | Acceptance Criteria | Phases/Steps |
|----|-------------|---------------------|--------------|
| REQ-1 | Newly created hash-schema plans use `<epic-id>-<date>-<plan-id>-<slug>` or `standalone-<date>-<plan-id>-<slug>`. Canonical `plan-id`, dependency/ledger references, and legacy `NNN-<slug>` folders remain unchanged; existing current hash folders continue resolving. | Focused parser/scaffold tests cover both hash grammars, epic/standalone creation, stable IDs, and unchanged legacy resolution. `test:PlanFolderPrefix.NewCreationAndCompatibility` | 1.1, 1.2, 3.1, 3.2 |
| REQ-2 | One script-owned migration command defaults to `-WhatIf`, inventories eligible current hash-schema folders, and emits a deterministic old/new mapping without moving anything. | Dry-run tests prove active/archived inventory, stable ordering, no mutation, and exclusion of legacy/already-prefixed folders. `test:PlanFolderPrefix.MigrationWhatIf` | 2.1, 3.1, 3.2 |
| REQ-3 | Migration refuses collisions, mismatched/missing plan identities, invalid epic membership, and paths outside the existing inventory before any move; the accepted mapping is the apply/resume input. | Preflight fixtures prove all-or-no-start refusal and byte-stable mapping replay. `test:PlanFolderPrefix.MigrationPreflight` | 2.1, 2.2, 3.1, 3.2 |
| REQ-4 | Explicit apply moves one mapped folder at a time under one existing repository lock or safe sequential operation, records completion, and resumes idempotently after interruption. Bulk migration is not run automatically by this plan. | Interruption fixtures prove completed moves are skipped, pending moves resume, canonical IDs remain stable, and a second run is a no-op. `test:PlanFolderPrefix.MigrationResume` | 2.2, 3.1, 3.2 |
| REQ-5 | Existing inventory/resolution, plan/epic scaffolding, archive/tests, plugin bundles, and generated catalogs support the new naming through shared helpers without launcher, review-run, or CI aggregation changes. | Installed-consumer and generated-drift checks pass across both grammars. `test:PlanFolderPrefix.ConsumerCompatibility` `test:bundle-no-drift` `test:dogfood-no-drift` | 1.2, 3.1, 3.2 |
