# Requirements

| ID | Requirement | Acceptance Criteria | Phases/Steps |
|----|-------------|---------------------|--------------|
| REQ-1 | The image provides the approved agent utility baseline. | `toolchain.tsv` is the sole additional-tool case/package owner; bootstrap packages are a distinct set. The structural contract proves manifest-to-installation-to-smoke equality with red mutations, and review plus the retained receipt prove every candidate smoke case ran as `autopilot`. `test:AutopilotContainer.ToolchainContract` · `review:cr` | 1.1, 1.2, 1.3, 2.2, 4.1 |
| REQ-2 | Conventional command names work safely for Debian-aliased packages. | Structural and image evidence prove exact root-owned `fd`/`bat` links, canonical targets, a non-writable parent, and successful invocation as `autopilot`. `test:AutopilotContainer.ToolchainContract` · `review:cr` | 1.2, 1.3, 2.2, 4.1 |
| REQ-3 | Tool acquisition and size comparison are bounded and diagnosable. | Packages resolve only from the Debian host allowlist; candidate validation always runs; unusable bases force relevance and produce closed candidate-only receipts; candidate gets 25 minutes before optional 10-minute base work; valid over-threshold results remain advisory. `test:AutopilotContainer.ToolchainContract` · `test:AutopilotContainer.GateRunnerContract` · `review:cr` | 1.1, 1.2, 1.3, 2.1, 2.2, 3.1, 4.1 |
| REQ-4 | Validation proves built-image behavior without slowing the ordinary suite. | `npm test` runs structural/security runner contracts only. The always-reported workflow invokes a trusted control runner; candidate smoke is secretless/socketless; unusable bases force image execution; detector failure and invalid result combinations fail closed; every terminal path has durable bounded evidence. `test:AutopilotContainer.ToolchainContract` · `test:AutopilotContainer.GateRunnerContract` · `test:Ci.WorkflowSecurityContract` · `test:CiGates.InventoryMatchesWorkflow` · `review:cr` | 1.3, 2.1, 2.2, 3.1, 4.1 |
| REQ-5 | Canonical and installed autopilot payloads remain synchronized. | Every Dockerfile/manifest/smoke mutation patch-bumps and regenerates dogfood/marketplace/registry in its owning step. The runner derives paths, verifies manifest-driven byte/hash parity, and writes deterministic terminal receipts. `test:AutopilotContainer.ToolchainContract` · `test:AutopilotContainer.GateRunnerContract` · `test:CiGates.InventoryMatchesWorkflow` · `review:cr` | 1.1, 1.2, 1.3, 2.1, 2.2, 3.1, 4.1 |
