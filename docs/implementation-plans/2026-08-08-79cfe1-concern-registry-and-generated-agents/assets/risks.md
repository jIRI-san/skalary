# Risks

| ID | Risk | Likelihood | Impact | Mitigation | Steps |
|----|------|------------|--------|------------|-------|
| RISK-1 | A defect in the shared template or unsafe registry substitution weakens all 14 concern agents at once. | Medium | High | Preserve migration digests; keep safety/ownership markers template-owned; bind every live file to the generated inventory; test hostile values and every agent rather than sampling one surface. | 1.1, 1.2, 2.1 |
| RISK-2 | Stale-agent pruning removes an unmanaged, installed, or user-modified file or escapes the intended output roots. | Low | High | Under the mutation lock, require generated ownership, manifest absence, Git tracking, exact `HEAD` bytes, no receipt owner, canonical confinement, and no linked/reparse path; fail closed with a remedy on any uncertainty. | 1.2, 2.1, 2.2 |
| RISK-3 | Generation succeeds while dogfood, manifests, plugin versions, marketplace data, registry hashes, or README metadata remain stale, or concurrent manifest writers lose one domain's changes. | Medium | High | Serialize manifest writers through one Git-resolved lock, run downstream authorities after every plugin mutation, add explicit-base CI evidence, seed every layer with drift, and require a clean second pass. | 1.2, 2.1, 2.2, 3.1 |
| RISK-4 | JSON order, process culture, or process-heavy fixtures make output nondeterministic or the gate too costly. | Low | Medium | Assert 24-case/4-runspace/120-second and 2-process/30-second bounds, cap 3 full-chain runs at 180 seconds, atomically assign integration tests to Slow, run both tiers, and retain existing ceilings. | 1.2, 2.1, 2.2, 3.1 |
| RISK-5 | A host below PowerShell 7.6 cannot enforce the native JSON Schema contract. | Low | Medium | Fail before rendering or writes with a distinct bounded capability outcome; preflight the container and test the simulated incapable-host path without a fallback validator. | 1.1, 1.2, 3.1 |
| RISK-6 | The prior-art index is incomplete because active folder `cda9da` has no `plan.md`. | Low | Low | Record the index error, limit reconciliation claims to the returned topic records, and preserve `b0c0d3` REQ-8/REQ-10 and both returned decisions explicitly. | 1.1 |
| RISK-7 | An interruption after the version-first commit point but before payload convergence leaves a version-only intermediate state. | Low | Low | Treat version-only as safe; rerun against the same Git baseline completes desired payloads without another bump, while clean replay remains a no-op. | 1.2, 2.1 |
| RISK-8 | A registry-derived test lets a bad taxonomy or host mapping approve itself. | Low | High | Keep the schema's exact seven-id enum and `model-allowlist.psd1` host policy independent; tests join all three sources and fail on disagreement. | 1.1, 3.1 |
| RISK-9 | One-time generated-marker adoption overwrites human-authored bytes or makes future missing-marker failures impossible to distinguish from migration. | Low | High | Bind adoption to immutable baseline digests, preserve outside bytes, emit durable marker/inventory ownership, and enable fail-closed marker rules only after migration output exists. | 1.1, 1.2, 2.1 |
| RISK-10 | Dogfood pruning races another installer or local sync, mistakes receipt-owned output for disposable dogfood, or loses prior generated authority after committed removal. | Low | High | Serialize through the mutation lock, validate the whole receipt store, resolve prior inventory through explicit base/dirty `HEAD`, and refuse every owned, modified, or unprovable candidate; update architecture and gate remedies in the same step. | 2.2, 3.1, 3.2 |
