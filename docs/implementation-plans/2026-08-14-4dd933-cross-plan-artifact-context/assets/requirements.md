# Requirements

| ID | Requirement | Acceptance Criteria | Phases/Steps |
|----|-------------|---------------------|--------------|
| REQ-1 | One resolver beside `Get-PlanIndex.ps1` accepts resolved plan IDs and a closed allowlist of artifact kinds, uses existing inventory/layout/asset resolvers, and returns content with plan ID, kind, repo-relative path, and relationship metadata. | Focused tests prove deterministic resolution across active/archived and assets/legacy layouts without scanning the plan corpus again. `test:PlanArtifactContext.Resolution` | 1.1, 3.1, 3.2 |
| REQ-2 | The resolver confines each regular file to the resolved plan, enforces per-artifact and aggregate byte bounds, treats content as untrusted data, and reports missing, refused, and oversized candidates explicitly. | Boundary, traversal/link, malformed plan, missing file, unsupported kind, exact-limit, and one-over cases fail closed without partial authority. `test:PlanArtifactContext.BoundsAndConfinement` | 1.2, 3.1, 3.2 |
| REQ-3 | Every consumed artifact records plan ID, kind, path, and relationship in existing `references.md` or the review scope; no dedicated receipt or provenance store is created. | Provenance tests prove deterministic records for accepted content and no record for refused content. `test:PlanArtifactContext.Provenance` | 2.1, 2.2, 3.1, 3.2 |
| REQ-4 | `/cip`, `/cep`, and optional plan-associated `/dr` and `/cr` use the same resolver after bounded candidate selection; current confirmed intent and architecture contracts remain authoritative. | Installed-consumer tests prove one resolver path, bounded context, authority fencing, and unchanged review-run v1 behavior. `test:PlanArtifactContext.Consumers` | 2.1, 2.2, 3.1, 3.2 |
| REQ-5 | Shared scripts and consuming plugins converge through existing script bundling, dogfood sync, registry/catalog, and test infrastructure. | Generated-drift and installed-consumer checks pass with no sidecar registry, context role, schema, or new lifecycle. `test:PlanArtifactContext.ConsumerInstall` `test:bundle-no-drift` `test:dogfood-no-drift` | 3.1, 3.2 |
