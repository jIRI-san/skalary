# Risks

| ID | Risk | Likelihood | Impact | Mitigation | Steps |
|----|------|------------|--------|------------|-------|
| RISK-1 | Host cannot create/access/preview the isolated worktree | Medium | High | Provide native/direct routes; stop before edits if tools target the source checkout; request explicit host action. Unavailable live host checks stay outstanding. | 1.1, 2.2 |
| RISK-2 | Source branch moves or dirty changes are silently omitted | Medium | High | Record SHA, explicit dirty-base choice, verify each new HEAD; mismatch stops that variant before mutation. | 1.1, 1.2 |
| RISK-3 | Prototypes are shallow mockups or expand into delivery | Medium | High | Demo the central vertical path with real connection points; disclose peripherals. Stop to revise the lightweight plan if scope requires production-scale work. | 1.1, 1.2, 2.2 |
| RISK-4 | Parallel variants collide through ports/services/output | Medium | Medium | Separate ports/output and serialize shared mutable resources; no parallelism requirement. | 1.1, 1.2 |
| RISK-5 | Prompt checks are mistaken for behavioral/live host proof | Medium | Medium | Focused contracts plus small fixture walkthroughs; report missing host verification explicitly, not as passed. | 1.2, 2.2 |
| RISK-6 | Losing prototypes disappear or selected code is treated as done | Medium | High | Retain until cleanup approval, report failures; identity-checked draft CIP handoff permits redesign. | 1.2 |
| RISK-7 | Stash overwrites plan or reintroduces unapproved choices | Medium | Medium | Read pinned stash selectively during implementation; copy/adapt only approved canonical content and regenerate catalogs, never blanket pop/apply. | 1.1, 2.1 |
| RISK-8 | Instruction-only workshop conflicts with repository rules requiring formal gates | Low | Medium | Preserve active contracts/safety; surface the conflict and ask rather than silently bypassing or expanding into another workflow. | 1.1 |
| RISK-9 | Forked CIP/another session loses workshop context | Medium | High | Send/paste a self-contained handoff block explicitly; verify selected identity before planning, never infer inherited context. | 1.2, 2.2 |
