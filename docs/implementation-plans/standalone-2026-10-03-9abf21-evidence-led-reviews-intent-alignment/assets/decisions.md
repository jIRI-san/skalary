# Decisions

- **Simplicity first.** Strengthen existing instructions and narrowly fix deterministic discovery/selection. No new plugin, review service, intent registry, generalized policy, persistent index or lifecycle.
- **Planning owns early alignment.** CEP/CIP catch consequential ambiguity; DR is the existing independent backstop, not the first checkpoint.
- **Capture OP meaning, not whole chats.** Selected dated/source-labelled statements and confirmed interpretations live within existing intent sections; bounded choices and historical reconciliation use existing decisions/references.
- **Design is the RFC.** Reuse `assets/design.md`; no parallel approved-design copy. OP reviews before implementation; delivery deviations do not rewrite confirmed intent.
- **History informs, not vetoes.** Search active/archived relevant intent; explicit OP supersession, scoped exceptions and deferment are legitimate. Active contracts/dependencies cannot be silently overridden.
- **Current budgets remain.** Zero delegates by default, current aliases/three-call ceiling, existing two mandatory pre-confirmation calls. No default panel/judge/rerun. Archived larger budgets/receipt mechanics are obsolete.
- **Practice library stays local and small.** Reuse standards and scoped notes with rationale/version/source/exception where relevant. No standards-grammar change or language handbook.
- **Evidence before advice.** Valid static traces count. Local style beats generic preference; demonstrated API/correctness/security failure beats defective precedent.
- **Target documentation uncertainty.** Only consequential named questions trigger official version-specific lookup; no private content in queries, fetched commands or automatic policy promotion.
- **Local focused development.** OP explicitly ruled out GitHub CI and minute-long routine eval cycles. Retain deterministic timing/timeout contracts and exact selectors; selected paid runs remain opt-in and may take longer.
- **Fix existing selector leakage.** Waza already has Case/Quick but runs every declared mode; selected functional cases must not trigger unrelated adversarial packs. Invalid cases fail before auth/provision/output.
- **Full authored suite, separate spending approval.** OP selected 12-20 scenarios with separately approved baseline/candidate comparison. A broader final local run is optional and separately approved. No paid performance guarantee.
- **Measure without new telemetry.** Reuse reports for observed cost/credits, latency, valid/missed/false findings and clarification usefulness; state unavailable metrics. No new cost ledger.
- **Test outcome, not vocabulary alone.** Keep deterministic graders for genuinely observable outcomes; use established subjective rubrics where semantics require them. State interaction fidelity limits.
- **One standalone plan.** Three usable slices and final OP-controlled evaluation fit the existing phase budget; no epic/dependent-plan machinery is needed.
- **OP accepted all pre-confirmation recommendations on 2026-10-03.** CEP captures in existing epic sections and participates in bounded history discovery/intake. Candidates carry explicit provenance with at most three 240-character snippets per artifact. Runtime ambiguity uses stop 42 and affected existing-plan reconfirmation. All task YAML in the five affected suites counts toward the catalogued 12-20 total; weak cases are revised before additions.
