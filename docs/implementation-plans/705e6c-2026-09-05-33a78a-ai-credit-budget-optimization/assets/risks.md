|----|------|------------|--------|------------|-------|
| RISK-1 | Cheaper models produce weak work that costs more through retries. | Medium | High | Route routine bounded work to Luna only when deterministic acceptance evidence exists; escalate once to Terra from concrete unresolved evidence; count every retry toward the three-call ceiling. | 1.2, 2.1, 2.3, 3.1, 4.2, 4.3 |
| RISK-2 | Sol or Opus gradually becomes a routine default again. | High | High | Name closed task classes, require an observable escalation reason in the dispatch prompt/result, exclude both from routine fallbacks, and add focused negative fixtures. | 1.1, 2.1, 2.3, 3.2, 4.3 |
| RISK-3 | Model prices or availability change after the plan is delivered. | High | Medium | Keep one dated human-readable snapshot with official links and named replacement fallbacks; review through GitHub's dashboard; add no hardcoded price engine. | 1.1, 3.3, 4.1, 4.3 |
| RISK-4 | A generated copy or launcher still enables long context. | Medium | High | Remove the configuration field and flag plumbing rather than changing only defaults; search active roots explicitly; sync canonical sources; test plugin, dogfood, launcher, schema, and example surfaces while excluding archives. | 1.2, 1.3, 3.2, 4.1, 4.2 |
| RISK-5 | Slimmed skills omit a rare but required guard or recovery path. | Medium | High | Move detail into installed assets rather than deleting unique contracts; preserve the decision edge in the entrypoint; test links, manifest inclusion, selected-path loading, and retained guards. | 2.2, 2.3, 4.2, 4.3 |
| RISK-6 | Replacing LLM judges with deterministic graders weakens eval signal or creates false green results. | Medium | High | Classify every task individually; use deterministic grading only for observable outputs/tool use/refusals; retain Terra for subjective judgment; keep fail-closed grader-execution convention tests. | 3.1, 3.2, 3.3, 4.2, 4.3 |

| RISK-8 | Canonical plugin instructions and dogfood/operator documentation drift. | Medium | Medium | Edit canonical plugin assets first, run existing synchronization, validate registry/marketplace and foreign-consumer installation, and reconcile docs in the same phase. | 2.2, 2.3, 4.1, 4.2, 4.3 |
| RISK-9 | The three-call ceiling blocks a genuinely difficult task without a safe continuation. | Medium | Medium | Stop with current evidence and ask for a new operator decision; do not hide a fourth call inside fallback, retry, or final review. | 2.1, 2.3, 4.3 |
| RISK-10 | Autopilot self-modification disrupts the run executing this plan. | Low | High | Execute this plan in manual mode, change canonical and generated runtime surfaces atomically within steps, and use focused launcher/config tests rather than running the mutating plan through autopilot. | 1.2, 4.2 |
