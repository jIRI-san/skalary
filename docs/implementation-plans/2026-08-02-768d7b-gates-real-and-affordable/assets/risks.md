# Risks

| ID | Risk | Likelihood | Impact | Mitigation |
|----|------|-----------|--------|------------|
| RISK-1 | A copied fixture leaks state between cases, so a test passes on a neighbour's side effects | Med | High | Each case receives its own filesystem copy of a pristine template under a freshly created random root that fails hard if it already exists. A randomised-order run must produce identical results — that is what detects ordering dependence; hashing does not, and `.git` mutates on its own so a whole-tree hash false-fails |
| RISK-2 | The rewrite gets fast by testing less | High | High | REQ-3's inventory is a subset assertion with an enumerated removal list. Install-confinement rejection cases are named must-keep, because a fixture-based rewrite cannot exercise write-path rejection and trimming pressure falls hardest on the executable evidence for `ARCH-Install-Confinement` |
| RISK-3 | `Run-UnitTests.ps1` turning fail-loud breaks an environment without Pester | Low | Med | Narrower than earlier drafts claimed: the script is bundled in **no** plugin, so there is no consumer install to migrate. Plan `003` REQ-15 covers the devcontainer. The failure message names the install command |
| RISK-4 | CI on both platforms is slow or flaky enough that people stop trusting it | Med | High | `windows-latest` is assumed ~2× `ubuntu-latest` and bills at 2× on private repos, so budgets and `timeout-minutes` are per leg, set above the hard ceiling. A platform-flaky test is fixed, or skipped with the reason recorded in the plan's capture log — not in the evidence receipt, which cannot express `skipped` (that is `863d97`'s contract, and a declared non-goal here) |
| RISK-5 | `-Force` enumeration reaches `.git`, `node_modules` or worktrees | Med | Med | Enumeration is an allowlist of payload roots rather than a substring denylist; paths are canonicalised and reparse points rejected. A negative test asserts `.git` is not enumerated |
| RISK-6 | An unrecognised stage string silently disables every evidence check while exiting 0 | Med | High | D7 closes the stage set and fails loudly on an unknown value; the skip emits a distinguishable signal so a downstream check cannot read it as a pass |
| RISK-7 | Plans from an older installed copy carry no stage anchor | Med | Med | A **missing** anchor means `drafted`, preserving today's behaviour so old plans keep being validated. The consequence is recorded rather than mitigated away: an old install keeps producing scaffolds that fail until it updates |
| RISK-8 | The workflow edit exposes credentials to PR-authored code | Med | High | Trigger stays `pull_request`; `permissions: contents: read`; `persist-credentials: false`; actions SHA-pinned; modules version-pinned with `-SkipPublisherCheck` and the globally trusted repository **removed**, since a version pin over an untrusted channel is not a control |
| RISK-9 | Later phases add runtime after the ceiling was fixed, so the plan ends slower than it certified | High | Med | Phase 7 makes `validate.ps1` parse more files and builds catalogs twice. The budget check runs again at step **9.3**, so the figure the operator reads is the final one — and because the ceiling was bound in Phase 1 rather than derived from a mid-plan measurement, later additions cannot quietly redefine success |
| RISK-10 | Gates chained in one CI script let one failure mask a suite that never ran | Med | High | The workflow invokes each gate as a separate named step. Plan-validation scope is recorded as a decision rather than left implicit |
| RISK-11 | Copying a full clone is slower than the clone it replaces | High | High | `git clone <localpath>` hardlinks the object store, so copying it 25 times is 25 full byte copies. D3 therefore lands the minimal synthetic fixture **before** the per-case copy, and Phase 2 records its achieved saving so a regression is visible rather than assumed |
| RISK-12 | The synthetic fixture loses `git tag` data that `Build-Registry` resolves versions from | Med | High | REQ-3 asserts the fixture carries tags. The test-name inventory cannot detect this class of loss, so it needs its own assertion |
| RISK-13 | The deferred constants work is dropped rather than moved | High | Med | D12 records the deferral explicitly and names `34088e` as the receiving child. This plan asserts nothing about it; `34088e` must pick it up in its own `/cip` or it is lost |
