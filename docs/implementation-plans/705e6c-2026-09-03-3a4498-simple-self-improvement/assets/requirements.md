# Requirements

| ID | Requirement | Acceptance Criteria | Phases/Steps |
|----|-------------|---------------------|--------------|
| REQ-1 | The bounded recent-learning reader remains the only SI input boundary and no longer depends on proposal lifecycle state. | It reads only committed `docs/feedback/recent-learning.md`; retains the 16 KiB, 10-item, strict metadata, completed source-plan, source-commit ancestry, citation, secret, and collision-safe fence checks; returns distinct `missing`, `empty`, `valid`, and `stale` states; malformed, oversized, secret-containing, and uncited input fails visibly; receipt/state parameters and writes are absent. `test:RecentLearning.BoundedRead` `test:RecentLearning.InvalidInputRefusal` | 1.1, 1.3, 3.3 |
| REQ-2 | `/si` is one stateless local interaction that presents cited proposals and applies only individual operator selections. | A valid handoff yields at most five proposals ordered by recurrence, severity, blast radius, then cost; every proposal names citations, expected effect, target files, benefits, pros/cons, `effort: 1-10`, and `complexity: 1-10`; VS Code and CLI expose equivalent choices; no selection, missing input, or empty input produces no write; selected edits occur in the current worktree without branch or PR automation. `test:SelfImprovement.DirectSelection` | 1.2, 1.3, 3.3 |
| REQ-3 | Direct SI writes are physically confined to selected canonical Markdown customization sources. | Pre-write and post-write checks allow only `.github/copilot-instructions.md`, canonical plugin skill/agent/prompt Markdown, `docs/design-notes/**/*.md`, and `docs/architecture-notes/**/*.md`; they refuse workflows/actions, generated `.github` copies, scripts/code, schemas/config, plans/runtime state, absolute/traversal paths, and link escapes; a selected dirty target stops for operator action; trusted sync runs only after a selected canonical plugin Markdown edit. `test:SelfImprovement.WriteScope` | 1.2, 1.3, 3.2, 3.3 |
| REQ-4 | `/pfb` remains useful without a queue or durable verdict. | Interactive `/pfb` resolves one completed plan, compares all five confirmed intent sections against cited delivery evidence, presents one of `full`, `partial`, or `missed`, collects operator corrections as data, and invokes `/cip` only when the operator requests a correction plan; headless completion does not invoke or queue PFB and no feedback file is written. `test:PostPlanFeedback.Stateless` | 2.1, 2.3, 3.1, 3.3 |
| REQ-5 | Obsolete self-improvement state and publication machinery is deleted without compatibility layers. | Active source, manifest, dogfood, catalogs, docs, and tests contain no due/run/proposal lifecycle, queue, receipt, CAS, repair, archive, cross-repository transport, worktree/branch/PR publication, SI schemas, `docs/self-improvement/**`, or `docs/feedback/queue.md`; `docs/feedback/recent-learning.md` remains. `test:SelfImprovement.RetiredStateResidue` | 2.2, 2.3, 3.1, 3.2, 3.3 |
| REQ-6 | `/ci`, autopilot, and plugin packaging consume only the retained direct SI/PFB surface. | Interactive `/ci` may offer stateless `/pfb`; headless autopilot skips PFB and performs no SI due enqueue; the plugin manifest declares only retained prompts, skills, Markdown assets, reader/guard closures, and focused evals; install/uninstall leaves no retired payload. `test:SelfImprovement.Integration` `test:SelfImprovement.ConsumerInstall` | 1.1, 2.1, 2.2, 2.3, 3.2, 3.3 |
| REQ-7 | Canonical source, generated distribution, active guidance, and focused tests close together. | Existing script sync, registry, marketplace, and dogfood generators run in repository order; drift checks and focused consumer installation pass; self-improvement design guidance and operator docs describe only the direct flow; the superseded cross-repo exploration is absent from the active index; no new schema, state file, lifecycle wrapper, or synchronization mechanism is added. `test:SelfImprovement.Distribution` `review:cr` | 2.2, 2.3, 3.1, 3.2, 3.3 |
| REQ-8 | Failure and cost behavior stays simple and visible. | Direct work uses zero delegates by default and the existing three-call ceiling; stale/invalid input, refused targets, dirty selected files, sync failure, and validation failure stop visibly; any mutation leaves a readable Git diff and never claims rollback; interrupted stateless interaction is rerun rather than repaired. `test:SelfImprovement.VisibleFailure` `review:cr` | 1.2, 1.3, 3.1, 3.2, 3.3 |
